# web

The site at [tejesh18.github.io/ai-hype-checker](https://tejesh18.github.io/ai-hype-checker/). React + TypeScript, built with Vite.

It reads `data.json` from the AWS pipeline through CloudFront and falls back to the snapshot in `public/` if that's unreachable. `public/model.json` is the TF-IDF model; `src/lib/classifier.ts` runs it in the browser for the "check your own text" page.

```bash
npm install
npm run dev       # http://localhost:5173/ai-hype-checker/
npm test          # includes a check that the classifier matches scikit-learn
npm run build
```

`public/data.json`, `public/model.json` and `src/lib/__fixtures__/parity.json` are generated by `uv run aiwash site` from the repo root. Pushing to `main` deploys through `.github/workflows/pages.yml`.
